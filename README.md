# Senko — автономный Discord-бот 🦊

Senko работает **без OpenAI API и без других сервисов генерации текста**.
Общение основано на локальных правилах, контексте, настроении и сохранённых пользователем фактах.

## Возможности

- Общение по обращениям «Сенко», упоминанию бота, в выделенном канале и в личных сообщениях
- Простая контекстная память текущего разговора (в оперативной памяти, исчезает при перезапуске)
- Добровольно сохранённые факты из `/запомни` и `/группа_запомни`
- Система настроения, отношений, листиков, инвентаря, магазина и мини-игр
- Самостоятельные действия и факт дня
- Совместимость со старым `data.json`

**Ограничение:** ответы сценарные, поэтому Сенko не сможет гибко отвечать на произвольные вопросы как языковая модель. Локальный движок не использует интернет.

## Установка

Python 3.10+:

```bash
python -m pip install -r requirements.txt
```

Создайте `.env` рядом с `bot.py`:

```dotenv
DISCORD_TOKEN=your-discord-bot-token
SENKO_CHANNEL_ID=your-channel-id
SENKO_CHAT_CHANNEL_ID=your-channel-id
# SENKO_GUILD_ID=your-server-id
# SENKO_DATA_FILE=data.json
```

Запустите:

```bash
python bot.py
```

Для обработки обычных сообщений включите **Message Content Intent** в Discord Developer Portal.
Никакие OPENAI_API_KEY и OPENAI_MODEL не нужны.

## Память и приватность

- Личные записи создаются через `/запомни`, управляются через `/память`.
- Память сервера сохраняется отдельно для каждого сервера; права удаления учитываются.
- Сообщения, не адресованные Senko, больше не записываются обработчиком чата.
- Короткий контекст разговора хранится только в RAM; для полного удаления временного контекста есть `/память выключить и удалить` и `/память очистить`.
- В существующем `data.json` могли остаться старые поля, созданные прежними версиями: перед публикацией или переносом проверяйте его на личные данные. При миграции данные не стираются автоматически.

## Тесты

```bash
python -m unittest -v test_senko_dialogue.py
```

## Файлы

- `bot.py` — команды Discord, хранилище и события.
- `senko_dialogue.py` — автономный диалоговый движок.
- `test_senko_dialogue.py` — тесты локального общения.

Внешняя зависимость `aiohttp` остаётся **только для проверки ссылок на изображения/GIF**, а не для AI.
